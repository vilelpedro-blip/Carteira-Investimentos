# Marketing Ideas for SaaS (local import)

## How to use

1) If product marketing context exists, read it first:
- `.agents/product-marketing-context.md` (or legacy `.claude/product-marketing-context.md`)

2) If context is missing, ask only what’s needed:
- product + ICP/audience
- stage (pre-launch / early / growth / scale)
- resources (time, budget, team)
- constraints (channels you won’t use, geo, compliance)

3) Recommend **3–5** most relevant ideas, then:
- explain why they fit
- give concrete implementation steps
- propose a lightweight 1–2 week plan

- Growth: paid acquisition, partnerships, events
- Scale: brand campaigns, internationalization, media acquisitions

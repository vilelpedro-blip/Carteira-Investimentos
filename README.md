# 🎯 Carteira de Investimentos

Aplicação web estática para gestão de carteira de investimentos.

## 🚀 Deploy
- **Vercel:** https://vercel.com (deploy automático)
- **GitHub Pages:** Configuração automática
- **Local:** `python3 -m http.server 8080`

## 📁 Arquivos
- `carteira-final.html` → Versão completa
- `teste-real.html` → Versão simplificada
- `carteira-prod.html` → Versão otimizada para produção

## ⚙️ Configuração
Nenhuma configuração necessária. Aplicação 100% estática.

## 📱 Funcionalidades
- Visualização de investimentos
- Cálculos automáticos
- Interface responsiva
- Sem backend necessário

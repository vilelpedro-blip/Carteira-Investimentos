## **16:00-16:07 — Resolução Final de Ferramentas e Acesso Docker**

### Problema Identificado:
- Docker CLI instalado via Homebrew, mas sem acesso ao socket
- Usuário 'node' não estava no grupo docker dentro do container
- Container root não tem shell básico (não é container Linux normal)

### Solução Implementada:

**1. Diagnóstico Completo:**
- Docker CLI instalado via Homebrew ✅
- Socket Docker existe: `/var/run/docker.sock` (root:docker, 988)
- Usuário 'node' não estava no grupo docker dentro do container

**2. Comandos Executados na VPS:**
```bash
# Adicionar usuário ao grupo docker (na VPS)
sudo usermod -aG docker $(docker exec openclaw-old id -un)

# Criar grupo docker dentro do container com GID correto
docker exec openclaw-old addgroup --gid 988 docker 2>/dev/null || true
docker exec openclaw-old usermod -aG docker node

# Reiniciar container para aplicar mudanças
docker restart openclaw-old
```

**3. Reinstalação Docker CLI:**
- Homebrew reinstalou Docker CLI após reinício
- Docker CLI agora em: `/data/linuxbrew/.linuxbrew/bin/docker`
